<Aside type="caution">Quark-J8 is a **Java 8** compatible fork of [Quark](https://github.com/BX-Team/Quark), which is used with plugins that designed to compatible with Java 8. If your plugin is developing under **Java 11 or later**, consider using the upstream repository!</Aside>

<Aside type="note">This documentation is mainly based to [Quark Documentation](https://bxteam.org/docs/quark), with some small changes.</Aside>

Quark-J8 is a lightweight, runtime dependency management system for plugins running on Minecraft server platforms. Providing a simple API, Quark-J8 makes it easy to download dependencies during your plugin startup without requiring shading or complex setup procedures.

# Cross-Platform Integration

Quark-J8 seamlessly integrates with various platforms, making it effortless to manage dependencies across different systems. Whether you're developing for Bukkit, BungeeCord or Sponge, Quark-J8 has you covered.

See the [Platforms](/getting-started/platforms) page for more information.

# Gradle Plugin

Quark-J8 provides a Gradle plugin that simplifies the integration of Quark into your project, allowing you to easily manage dependencies and configurations, without requiring complex setup procedures.
