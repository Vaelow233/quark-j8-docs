---

Quark-J8 supports multiple platforms. You can find all of them in the table below.

| Platform Name | Compatible With                  | Compatible Version        |
|---------------|----------------------------------|---------------------------|
| `bukkit`      | Bukkit / Spigot / Paper / Purpur | `1.8.8` - `1.21.10`       |
| `bungeecord`  | BungeeCord / Waterfall           | `1.19-R0.1` - `1.21-R0.4` |
| `fabric`      | Fabric                           | `Fabric Loader 0.14.25+`  |
| `sponge`      | SpongeVanilla / SpongeForge      | `1.16.5+`                 |

import {Aside} from "@astrojs/starlight/components";

<Aside type="note" title="How to use it?">To use Quark-J8 with a specific platform, you need to add the platform dependency to your project. See the [Installation](/getting-started/installation) page for more information.</Aside>
